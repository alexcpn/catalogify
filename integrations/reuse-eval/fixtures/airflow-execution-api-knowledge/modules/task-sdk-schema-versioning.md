# Responsibilities

This package is the contract for the supervisor-to-subprocess messages that a
lang-SDK coordinator (Java, Go, Rust) exchanges with the Python supervisor. It
holds no models of its own. `registered_models_by_name()` introspects the
message unions in `comms.py` and `processor.py`, so the snapshot always matches
what the decoder accepts. `SchemaVersionMigrator` walks the Cadwyn version chain
to convert a message between the head shape and a pinned lang-SDK version in
either direction. `resolve_body_class` maps a body to its registered model.

This contract is independent of the HTTP Execution API. A supervisor schema
change does not bump the HTTP version, and a route change does not bump this
one.

# Interfaces

| Symbol | Purpose |
| --- | --- |
| `registered_models_by_name` | Sorted map of every registered body class, used to write `schema.json`. |
| `resolve_body_class` | Returns the registered model for a message body. |
| `SchemaVersionMigrator` | Bidirectional in-process migrator between head and a pinned lang-SDK version. |
| `get_schema_version_migrator` | Builds the migrator for the supervisor's pinned version. |

# Dependencies

- Registers the unions defined in [Task SDK comms](../modules/task-sdk-comms.md) (`ToTask`, `ToSupervisor`) and the Dag processor unions in `airflow/dag_processing/processor.py`.
- Is separate from the HTTP contract in [Execution API versioning](../modules/execution-api-versioning.md).
- Its `schema.json` snapshot is generated by a prek hook and consumed by lang-SDK code generation.

# Gotchas

- `schema.json` is a generated snapshot. `c6e19e63a7` fixed the snapshot so that Go model generation works; regenerate it through the hook, do not edit it.
- Registration is automatic from the unions. Adding a body means appending it to the union; there is no separate list to update.
- The triggerer's unions are excluded on purpose. Lang-SDK coordinators do not handle the triggerer channel today.
- The schema migration added to the supervisor-child channel was introduced in `0920c770c8`; that is the commit to read before changing how messages are versioned.
