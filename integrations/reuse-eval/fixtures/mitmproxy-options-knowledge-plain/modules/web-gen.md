# Responsibilities

`web/gen/` keeps the web frontend in step with the Python source. Each script
imports the real Python objects, renders TypeScript or Python text, and writes
it into the frontend or into `mitmproxy/tools/web/`. The option generator turns
the declared options into `OptionsState`, `Option` and `defaultState`. The
backend generator writes the reverse-proxy protocol and syntax-highlight
enums. The columns generator copies a list out of the TypeScript source into
Python. The state generator writes a test fixture. `all` runs every `*.py` in
the directory. `tflow_js.py` is also run by `all` but was not analysed here.

# Interfaces

| Symbol | Purpose |
| --- | --- |
| `options_js.make()` | Build `_options_gen.ts` from `WebMaster(Options()).options`. Sorted by name. |
| `options_js._ts_type(t)` | Map Python types to TypeScript: `bool`, `string`, `number`, `string[]`, `string | undefined`, `number | undefined`. Raises `RuntimeError` for anything else. |
| `backend_consts.make()` | Write `ReverseProxyProtocols` from `ReverseMode`'s scheme literal and `SyntaxHighlight` from `SyntaxHighlight.__value__`. |
| `web_columns.extract_columns()` | Read names after the `// parsed by web/gen/web_columns` marker in `FlowColumns.tsx`. |
| `web_columns.make()` | Write `AVAILABLE_WEB_COLUMNS` to `mitmproxy/tools/web/web_columns.py`. |
| `state_js.make()` | Build the `_tbackendstate.ts` test fixture with a mocked `ServerInstance`. |

# Notes

The runner `web/gen/all` is a Bash script (`set -euxo pipefail`) that runs each
`web/gen/*.py` in turn. The points below were read from the code. No
risk-flagged commit in history was found for `web/gen`, so none is cited.

- **New option types break generation.** `_ts_type` raises `RuntimeError` for any type it does not list. Adding an option with a new typespec fails the generator, not the Python tests.
- **Generated files are not hand-edited.** Each header says "Auto-generated by", and `options_js` writes `null` defaults as `undefined`, which is the only shape difference from Python.
- **The column generator depends on a marker comment.** It matches `// parsed by web/gen/web_columns` followed by a list in `FlowColumns.tsx`. If the marker moves or the list is reformatted, the regex fails to match and the script errors on `match.group`. This is observed in the code; no commit in history covers it.
