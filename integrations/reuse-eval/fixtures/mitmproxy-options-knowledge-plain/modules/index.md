# Modules

* [options.md](options.md) - Core Options object: 28 declared options with types, defaults and help text.
* [optmanager.md](optmanager.md) - OptManager: typing, parsing, rollback, subscriptions, and config load/save.
* [cli-options.md](cli-options.md) - Command-line parsers for mitmproxy, mitmdump and mitmweb, built from the declarations.
* [web-ui-options.md](web-ui-options.md) - mitmweb's web_* options, auth, and the /options REST endpoints.
* [web-gen.md](web-gen.md) - Generators that keep the TypeScript frontend in step with the Python option and enum definitions.
* [proxy-modes.md](proxy-modes.md) - Proxy mode spec parsing and the listening server instance for each mode.
* [proxy-server.md](proxy-server.md) - Connection handler, context, and the layer command protocol that drives each connection.
