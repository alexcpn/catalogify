# mitmproxy option system and proxy core - knowledge bundle

Generated knowledge about how mitmproxy declares, manages and exposes its
options, and how the proxy server consumes them. Start with
[architecture/overview.md](architecture/overview.md), or open [index.md](index.md).

Generated by catalogify `0.11.0` from commit `181dfb00`. Scope: `mitmproxy/options.py`,
`mitmproxy/optmanager.py`, `mitmproxy/proxy/`, `mitmproxy/tools/` and `web/gen/`.
The bundle holds 12 concepts in 4 directories, plus the index files and
`log.md`.

## Check it

```
catalogify validate knowledge
catalogify verify knowledge
```

`verify` resolves every cited commit, interface symbol, relation and guardrail
against git. `validate` checks structure.

## Use it when changing code

Before editing a file, run `catalogify find <file>` and follow any guardrail
and playbook it returns. Agents that read the whole bundle up front spend more
tokens than they save.

## Correct it

Unresolved uncertainty is recorded in each concept's `open_questions`. These
are the highest-value gaps: they are the intent behind a guarantee or an
ordering rule that the code alone does not settle. `catalogify clarify` walks a
human through them, and an answer given there is marked with a sentinel and
survives later regeneration.
